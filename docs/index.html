Documentation & Setup Guide

Everything you need to run, build, and extend hf.app on your Mac.

Running hf.app locally

Make sure you have Xcode Command Line Tools installed and Osaurus running on localhost:1337.

BASH
# 1. Clone the repository git clone https://github.com/8b-is/hf-mac.git cd hf-mac # 2. Run with SwiftPM swift run

Prerequisites: Launch Osaurus on localhost:1337, pull your favorite model (e.g., Llama, Qwen, Phi), then click Refresh in the Run tab of hf.app.

Swift Codebase Structure

`hf.app` is organized into clean, single-responsibility Swift files under Sources/HFMac/:

SWIFT ARCHITECTURE
Sources/HFMac/ ├── Services.swift # HubClient (HF Hub REST) & OsaurusClient (OpenAI /v1) ├── HFMacApp.swift # @main App, WindowGroup & MenuBarExtra ├── Views.swift # Browse / Run / Your Models UI & Menu Bar agent ├── Keychain.swift # Secure HF Token storage in macOS Keychain ├── OfflineStore.swift # Local persistence & cached model state └── Theme.swift # Native macOS dark-mode styling tokens

Keychain & Entitlements Security

Your Hugging Face API tokens are stored using macOS Security.framework Services inside the system Keychain (dev.peterl.hfmac.token). See our full SECURITY.md Policy.
